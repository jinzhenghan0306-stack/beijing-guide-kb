# 03 · 文案创作

> **媒体视角，不口语化，不带个人视角，但要有实用性。** 让用户觉得"这是一个靠谱的资讯台"，不是"某个人的碎碎念"。

## 一、标题规范

- 固定格式：**`北京X月X日生活指南`**（小红书标题 + 正文首行一致）
- 封面主标题：**3-7 个字**（如 "暴雨应对" / "购房新政"），大字、居中、信息密度高
- 主标题 + 副标题组合：主标题抓眼球，副标题补信息量

## 二、正文 332 法则

| 结构 | 内容 | 目的 |
|---|---|---|
| **前 3 秒** | 第一行直接给最有冲击力的变化 | 抓住滑屏的手 |
| **中 3 段** | 每条信息：变化 → 影响 → 行动建议 | 让用户能"用" |
| **后 2 项** | 互动钩子 + 话题标签 | 推收藏和评论 |

每条信息结构模板：

```
【交通】三环新增大站快车，368路开通
今天起，三环主路开通大站快车，全程少停12站，通勤能省20分钟。
（影响 + 行动建议）赶早晚高峰的建议先试试这条线。
```

## 三、互动钩子库（文末二选一）

- "今天你堵在哪了？评论区聊聊"
- "你家附近有新变化吗？欢迎补充"
- "这条对你有用的话，收藏起来，明天出门前看一眼"

## 四、话题标签策略

- 每篇 3-6 个，组合：**主话题 + 场景话题 + 地域话题**
- 例：`#北京生活 #北京出行 #北京天气 #打工人日常 #北京本地生活`
- 不用冷门长尾词堆砌，1 个主话题保证流量池

## 五、去AI味检查表（发稿前必过）

- [ ] 没有"首先/其次/最后"式排列
- [ ] 没有空洞的形容词堆砌（"值得关注""具有重要意义"）
- [ ] 没有三段式排比口号
- [ ] 句子长短错落，不全是整齐划一的短句
- [ ] 数字具体（"省20分钟"不说"节省大量时间"）
- [ ] 媒体视角：不说"我觉得""我认为"

## 六、配图文字规范

- 图片上的字 = 正文的**提炼**，不是复制
- 每张卡 1 个信息点，标题 ≤ 12 字，副文 ≤ 40 字
- 检查无截断、无错别字（发布前逐张过）
