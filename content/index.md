# 北京生活指南 · 内容创作知识库

> 这个账号的一切创作逻辑都在这里。**每次创作前必读，每次创作后复盘更新。**

## 账号一句话定位

**北京生活变化，一条就够了。** 帮北京打工人/居民，每天用一条笔记讲清"北京今天发生了什么、对你有什么影响、你该怎么办"。

## 六大模块

| 模块 | 解决什么 | 入口 |
|---|---|---|
| 01 信息获取 | 全面、稳定、真实、时效地拿到信息 | [[01-information\|信息获取]] |
| 02 选题打分 | 选出来的爆款，不是写出来的 | [[02-topic-selection\|选题打分]] |
| 03 文案创作 | 标题、正文、钩子、去AI味 | [[03-copywriting\|文案创作]] |
| 04 排版封面 | 用户愿不愿意点进来 | [[04-design-cover\|排版封面]] |
| 05 发布运营 | 节奏、互动、数据复盘 | [[05-publishing\|发布运营]] |
| 06 趋势跟踪 | 保持时效性，跟上爆款风向 | [[06-trend-tracking\|趋势跟踪]] |

## 创作前必读流程

1. 读 [[06-trend-tracking|趋势跟踪]] —— 确认当前审美风向没有变
2. 读 [[04-design-cover|排版封面]] 的自查清单 —— 风格审视
3. 采集信息 → [[02-topic-selection|选题打分]] 筛选 5-6 条
4. 按 [[03-copywriting|文案创作]] 规范写文案
5. 发布 → 复盘 → 更新 [[changelog|更新日志]]

## 核心公式速记

- **爆款选题** = 变化 × 影响面 × 行动建议
- **粘性** = 四固定（标题固定 / 结构固定 / 时间固定 / 钩子固定）
- **时效** = T-1 采 → T-0 验 → 晚 19-20 点发
- **视觉** = 字少图大、留白、层级（2026 趋势）
