# 04 · 排版封面

> **封面决定"点不点进来"，排版决定"留不留下来"。**
> 2026 趋势：字少图大、留白、层级分明。旧式"满底色块大字报"CTR 只有 3.2%，三阶式布局可到 12.8%。

## 一、封面三阶式布局（母版）

| 区域 | 位置 | 规范 |
|---|---|---|
| 主标题 | 上方 | 3-7 字，80-120px，最多两行 |
| 核心信息图 | 中部 | **新闻实景图**（主图 = 新闻原文第一张实景照，不用 AI 图） |
| 底部条 | 下方 | 日期 + 账号名，固定样式 |

硬性数值：
- 文字占封面面积 **≤ 40%**，图才是主角
- 大留白，标题上下留呼吸空间
- 一张封面只讲**一个**核心信息点

## 二、四固定视觉符号系统（保辨识度）

> 视觉风格统一的账号，粉丝转化率比随机风格高 40%。用户 0.5 秒内认出"这是那个北京生活指南" = 赢。

1. **固定色调**：深蓝 #185FA5 + 珊瑚 #D85A30 + 白底（延续账号体系）
2. **固定字体**：全平台统一一套中文字体（Hiragino Sans GB 等），不混用
3. **固定构图**：主标题固定在上、日期角标固定右下
4. **固定元素**：每条卡片左上角带类别角标（交通/商业/民生/便民）

## 三、配图序列动线（6-9 张）

```
封面 → 暴雨/交通（最紧急）→ 交通 2 → 民生 1 → 商业 1 → 便民 1 → 结尾互动页
```

- 第一张封面必须抓眼球
- 信息卡顺序 = 选题优先级顺序
- 结尾页固定：互动钩子 + 关注引导

## 四、字号数值规范

| 元素 | 字号 | 说明 |
|---|---|---|
| 封面主标题 | 80-120px | 3-7 字，宁可大 |
| 卡片标题 | 54-58px | 一行放不下自动换行 |
| 卡片副文 | 28-34px | 最多两行 |
| 底部日期 | 24px | 固定位置 |

## 五、创作前自查清单（每次必过）

- [ ] 风格是否符合当前小红书审美？（先读 [[06-trend-tracking|趋势跟踪]]）
- [ ] 封面主标题 ≤ 7 字？文字面积 ≤ 40%？
- [ ] 用的是新闻实景图，不是 AI 图？
- [ ] 四固定：色调/字体/构图/元素都统一？
- [ ] 所有文字无截断、无错别字？
- [ ] 标题、正文、封面字三者信息一致？

## 六、历史教训

- `textlength` 对中文字体宽度计算偏紧 → 用 `textbbox` + padding 加大
- 文字锚点用 `mm`（居中），`lm` 是左中对齐会导致右溢出截断
- 长标题必须预检宽度，生成前先算，超限预警
