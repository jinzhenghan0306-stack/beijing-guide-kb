# 04 · 排版封面

> **封面决定"点不点进来"，排版决定"留不留下来"。**
> 2026 趋势：字少图大、留白、层级分明。旧式"满底色块大字报"CTR 只有 3.2%，三阶式布局可到 12.8%。

## 一、封面三阶式布局（母版）

| 区域 | 位置 | 规范 |
|---|---|---|
| 主标题 | 上方 | 3-7 字，80-120px，最多两行 |
| 核心信息图 | 中部 | **新闻实景图**（主图 = 新闻原文第一张实景照，不用 AI 图） |
| 底部条 | 下方 | 日期 + 账号名，固定样式 |

硬性数值：
- 文字占封面面积 **≤ 40%**，图才是主角
- 大留白，标题上下留呼吸空间
- 一张封面只讲**一个**核心信息点

## 二、四固定视觉符号系统（保辨识度）

> 视觉风格统一的账号，粉丝转化率比随机风格高 40%。用户 0.5 秒内认出"这是那个北京生活指南" = 赢。

1. **固定色调**：深蓝 #2D3142 + 珊瑚粉 #FF4D6D + 米白 #FDF6F3（延续账号体系）
2. **固定字体**：全平台统一一套中文字体（Hiragino Sans GB 等），不混用
3. **固定构图**：主标题固定在上、日期角标固定右下
4. **固定元素**：顶部角标「X月X日 · 早安北京」（右上方固定位置）

## 三、配图序列动线（6-7 张）

```
封面（最爆单一事件）→ 信息页1 → 信息页2 → ... → 信息页N
```

- 第一张封面必须抓眼球（当天最爆的一件事，不做总览）
- 信息卡顺序 = 选题优先级顺序（政策 > 交通 > 看展 > 商业 > 便民）
- 无清单总结页、无互动页（已删除）

## 四、字号数值规范

| 元素 | 字号 | 说明 |
|---|---|---|
| 封面主标题 | 80-120px | 3-7 字，宁可大 |
| 卡片标题 | 54-58px | 一行放不下自动换行 |
| 卡片副文 | 28-34px | 最多两行 |
| 底部日期 | 24px | 固定位置 |

## 五、创作前自查清单（每次必过）

- [ ] 风格是否符合当前小红书审美？（先读 [[06-trend-tracking|趋势跟踪]]）
- [ ] 封面主标题 ≤ 7 字？文字面积 ≤ 40%？
- [ ] 用的是新闻实景图，不是 AI 图？
- [ ] 四固定：色调/字体/构图/元素都统一？
- [ ] 所有文字无截断、无错别字？
- [ ] 标题、正文、封面字三者信息一致？

## 六、历史教训

- `textlength` 对中文字体宽度计算偏紧 → 用 `textbbox` + padding 加大
- 文字锚点用 `mm`（居中），`lm` 是左中对齐会导致右溢出截断
- 长标题必须预检宽度，生成前先算，超限预警

## 七、模板系统 v6.1（2026-08-13 最终定版）

> **设计哲学：编辑式大字报 + 苹果式液态玻璃 + 自适应配色**
> 封面抓爆点，信息页统一淡雅，玻璃质感轻微可见，背景随实景图色调微调。

### 1. 封面逻辑

- **封面 = 最爆的单一事件**（不是总览），排序优先级：政策 > 交通 > 看展 > 商业 > 便民
- 封面背景 = C虚化胶片 + 主题元素剪影（房产=房子/政策=法锤/交通=立交桥/科技=机器人/经济=K线/通用=天际线）
- 封面样式 = 编辑式大字报：大标题双色（深蓝+珊瑚粉）+ 正文段落直接排布 + 底部来源线
- 顶部角标：「X月X日 · 早安北京」

### 2. 信息页逻辑

- 背景 = B留白几何 + **液态玻璃面板**（圆角36px，磨砂微模糊+边缘折射高光+细微噪点+极淡外阴影）
- 自适应配色：`extract_dominant_color()` 提取实景图中心区域平均色 → 降饱和30% → 和base accent做70:30混合
- 色调统一：`ImageEnhance.Color.enhance(0.75)` 去色25% + 米白纱罩(alpha=40)
- **实景图卡片 = contain 模式**：按原比例缩放不裁切（`draw_photo_card` 根据图片宽高比自动计算卡片尺寸）
- 结构：标题顶置1/4 + 编辑式整段描述 + 圆角实景图卡片 + 底部长横线来源标注

### 3. 玻璃系统

| 位置 | 函数 | 效果 |
|---|---|---|
| 封面 | `glass_veil(alpha_top=25, alpha_bottom=5)` | 全屏极淡白色叠层 + 对角柔光，让背景房子/天际线透出 |
| 信息页 | `liquid_glass(img, mx=45, my_top=165, my_bot=195, radius=36)` | 圆角面板：微模糊(blur=5) + 混白12% + 边缘折射高光 + 800点噪点 + 外阴影 |
